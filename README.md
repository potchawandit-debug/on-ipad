# on-ipad

## kingshot-translator

สกิลแปลแชทเกม Kingshot (ไทย ⇄ English / 繁體中文 / 한국어)

- พิมพ์ไทย → ได้ 3 ภาษาใน code block แยกกัน กด copy ได้ทันที + แปลกลับเป็นไทยว่าเพื่อนจะอ่านแล้วเข้าใจอะไร
- วางข้อความภาษาอื่น → แปลเป็นไทย
- แคปภาพแชท → อ่านทีละข้อความ แยกชื่อคนพูด แล้วแปลเป็นไทย

### ติดตั้งใน Claude app (iPad / เว็บ)

1. ดาวน์โหลด `kingshot-translator.zip` จาก repo นี้
2. เปิด claude.ai → Settings → Capabilities → Skills → Upload skill
3. เลือกไฟล์ zip แล้วเปิดใช้งาน
4. เริ่มแชทใหม่ แล้วพิมพ์ไทยหรือส่งภาพแชทเกมมาได้เลย
